### 📊 Customer Transaction Analysis Using Excel

### 1\. Project Overview

The Customer Transaction Analysis project focuses on analyzing customer purchasing behavior and sales performance using Microsoft Excel. The project uses a dataset of 250 customer transactions to identify purchasing patterns, evaluate revenue, and understand the relationship between product quantity and total sales amount.

The main aim of this project is to transform raw transaction data into meaningful insights that can support better business decisions.

### 2\. Project Objectives

* To analyze customer transaction data using Excel.

* To identify the most frequently purchased product.

* To calculate and summarize total transaction amounts.

* To analyze customer segments, payment methods, and regions.

* To perform regression analysis to understand the relationship between quantity and total amount.

* To use Excel's analytical tools to support data-driven decision-making.

### 3\. Tools and Technologies Used

* Microsoft Excel

* Excel formulas and functions

* Sorting and filtering

* Data visualization and conditional formatting

* What-If Analysis and Scenario Manager

* Goal Seek

* Data Analysis ToolPak

* Regression analysis

### 4\. Project Workbook Structure

The workbook contains the following sheets:

1\. Final Project Dataset

Contains the original customer transaction data, including payment methods, regions, customer segments, customer dates, and total transaction amounts.

2\. Scenario Summary

Displays different business scenarios, such as pessimistic and normal conditions, to compare possible outcomes by changing input values.

3\. Analysis

Used to perform calculations and explore the dataset to identify useful business insights.

4\. Regression Analysis

Contains the regression output generated using Excel's Data Analysis ToolPak to examine the relationship between quantity and total amount.

5\. Product Analysis

Summarizes purchase frequency by product and identifies the most frequently purchased product.

### 5\. Key Findings

Based on the analysis performed:

* Total transaction amount: 229,192.47

* Total observations: 250 transactions

* Most frequently purchased product: Bookshelf

* Bookshelf purchase frequency: 35

* Regression R-squared: Approximately 0.2098

* Quantity coefficient: Approximately 353.79

These results are based on the Excel screenshots and should be verified against the final workbook before submission.

### 7\. Regression Analysis

Regression analysis was conducted to examine the relationship between quantity and total transaction amount.

The estimated regression equation is:

Total Amount = −148.85 + 353.79 × Quantity

The R-squared value is approximately 0.2098, meaning that the model explains about 20.98% of the variation in total transaction amount in this dataset.

The quantity coefficient is positive, indicating that higher quantities are associated with higher total amounts in the fitted model. However, this relationship does not by itself establish causation.

### 8\. Scenario Analysis

Scenario analysis was used to compare different possible outcomes by changing selected input values.

* Pessimistic scenario: Represents a lower-value assumption.

* Normal scenario: Represents a more typical business assumption.

Goal Seek was also used to find an input value that would produce a specified target result. Scenario values should be checked against the intended assumptions in the final workbook.
